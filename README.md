# DAC Awake 2

Android segedalkalmazas USB DAC-ok standby/sleep miatti elso hang-levagasahoz.

## V2 ujdonsagok
- allithato frekvencia: 10 Hz - 22 kHz
- 18 Hz es 19 kHz gyorsgomb
- allithato jelszint: -90 ... -20 dBFS
- a beallitasok megjegyzese
- futas kozbeni parameterallitas
- 48 kHz / 16 bit / sztereo AudioTrack
- nem ker audio fokuszt
- foreground service, Start/Stop

A jelenlegi tesztelt kiindulasi pont AB13X USB Audio DAC-hoz: **18 Hz / -50 dBFS**.
